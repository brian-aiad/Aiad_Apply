# Objective

Describe the finished result, not just the activity to perform.

## Required outcomes

- List the concrete features, fixes, or artifacts that must exist.

## Constraints

- State behavior that must remain unchanged.
- Name compatibility, security, privacy, design, or performance boundaries.
- Name anything that must not be touched.

## Inputs and references

- Point to relevant files, screenshots, URLs, issues, examples, or specifications.

## Verification

- List the commands, tests, measurements, or visual checks that prove the work is correct.

## Definition of done

The task is complete only when every required outcome is implemented, the relevant verification
passes, regressions are addressed, and `docs/overnight/runs/LAST_RESULT.md` records the evidence.

## External actions explicitly authorized

None unless listed here. Source edits and local tests are allowed; deployment, purchases, account
changes, communications, destructive data operations, and production/shared-database writes are
not implied.
